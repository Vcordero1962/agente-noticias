# Diario de Estudio y Agente de Noticias

Aplicación web, sin servidor ni instalación, para:

- Registrar sesiones de estudio y mantener rachas.
- Buscar noticias con fuentes reales (cada noticia lleva medio y enlace verificable).
- Gestionar agenda y reuniones: temas a llevar, actas y acuerdos.
- Generar informes descargables (Word, PDF y Markdown).

## Cómo abrirla

- Abre `index.html` con doble clic en el navegador, o
- publícala en GitHub Pages y entra desde la URL del sitio.

## Datos y privacidad

Todos los datos viven solo en tu navegador (`localStorage`). No usa claves de API ni backend.
Limpiar los datos del navegador borra tus registros: exporta una copia desde la propia app.
